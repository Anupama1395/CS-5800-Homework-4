# CS 5800 Homework 4

This repository contains five independent Java programs demonstrating inheritance, interfaces, polymorphism, aggregation, and composition.

## Project structure

- `Question1-Inheritance` - Employee inheritance hierarchy
- `Question2-Interface` - Payable interface with freelancers and vendor invoices
- `Question3-Polymorphism` - Ship, CruiseShip, and CargoShip polymorphism
- `Question4-Aggregation` - Course with multiple instructors and textbooks
- `Question5-Composition` - Folder and File composition

## Compile and run

Open a terminal in each question folder and run the commands shown below.

### Question 1

```bash
cd Question1-Inheritance
javac *.java
java InheritanceDriver
```

### Question 2

```bash
cd Question2-Interface
javac *.java
java PayableDriver
```

### Question 3

```bash
cd Question3-Polymorphism
javac *.java
java ShipDriver
```

### Question 4

```bash
cd Question4-Aggregation
javac *.java
java CourseDriver
```

### Question 5

```bash
cd Question5-Composition
javac *.java
java FileSystemDriver
```

After running each program, capture a screenshot of its console output for the submission document.
